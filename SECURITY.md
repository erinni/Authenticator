# Politica di sicurezza

## Segnalare una vulnerabilità
Non aprire issue pubbliche per problemi di sicurezza.
Usa la funzione **"Report a vulnerability"** (GitHub Private Vulnerability Reporting) nella scheda *Security* di questa repository.

Includi, se possibile: descrizione, impatto, passi per riprodurre, versione/piattaforma interessata.

## Tempi di risposta
- Conferma di ricezione: entro 72 ore.
- Valutazione iniziale: entro 7 giorni.
- Divulgazione coordinata dopo il rilascio della correzione (indicativamente entro 90 giorni).

## Versioni supportate
Il progetto è in fase di sviluppo iniziale: nessuna versione è ancora considerata stabile.
